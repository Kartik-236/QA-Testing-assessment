# ByteShift QA Testing Report

Manual QA Testing Report for **ByteShift v2.0**, a secure data sanitization and IT asset disposal tool developed in Python.

This repository contains:
- Detailed manual QA testing documentation
- Test scenarios and test cases
- Bug reports and observed limitations
- Security-oriented testing observations
- UI and workflow screenshots

The report was prepared as part of a QA/Testing Internship technical assessment submission for Sciqus Technologies.

> Note: ByteShift is an actively developed project. Some findings include both manually observed issues and implementation/security analysis performed during ongoing development and testing.
